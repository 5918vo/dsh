# dsh

A repository the dsh-superagent prototype works on.

## React Todo List

A small, self-contained React + TypeScript todo app built with Vite, under `src/`.

Features:

- Add a todo by typing and pressing Enter (or clicking **添加**).
- Toggle a todo complete/incomplete with the checkbox.
- Edit a todo by double-clicking its text (or the edit button); Enter saves, Esc cancels.
- Delete a single todo, or clear all completed ones.
- Filter by **全部 / 未完成 / 已完成**.
- Todos are saved to `localStorage` and restored on reload.

### Development

```bash
npm install
npm run dev      # start the dev server
npm test         # run the unit tests
npm run build    # type-check and build for production
```
